# MinimalPDFReader
A lightweight and distraction-free PDF reader for Windows 11, with touchpad and touchscreen zoom, fit-to-width viewing, and a minimal interface.

## 下載與安裝

**適用系統：Windows 11 64 位元（Intel / AMD）**  
**版本：v1.0 試用版**

### [下載 v1.0 安裝包（約 3 MB）](https://github.com/SEOGWAN-AI/MinimalPDFReader/raw/refs/heads/main/downloads/MinimalPDFReader-Setup-Win11-v1.0.exe)

1. 下載 `MinimalPDFReader-Setup-Win11-v1.0.exe`。
2. 雙擊安裝包，按「安裝」。
3. 安裝完成後，從桌面或開始功能表開啟閱讀器，選擇 PDF 文件。

無需自行編譯，也無需安裝 Python 或 Zig。預設安裝到目前使用者的帳戶，無需管理員權限。

本版本尚未進行數位簽章。完整操作及版本狀態請參閱[使用說明](使用說明.txt)。

## Download and install

[Download the Windows 11 x64 installer](https://github.com/SEOGWAN-AI/MinimalPDFReader/raw/refs/heads/main/downloads/MinimalPDFReader-Setup-Win11-v1.0.exe), run it, and click **Install**.
Then launch the reader from the desktop or Start menu. No compiler or administrator rights are required.

This is an unsigned v1.0 trial build for Intel/AMD 64-bit Windows 11.
