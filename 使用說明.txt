極簡 PDF 閱讀器 1.0 — Windows 11 x64 安裝版／試用版

使用方法
安裝版：雙擊 MinimalPDFReader-Setup-Win11-v1.0.exe，再按「安裝」。
預設為目前使用者安裝，無需管理員權限。
安裝後可從桌面或開始功能表開啟。
程式位置為 %LOCALAPPDATA%\Programs\MinimalPDFReader。
可從 Windows「設定 → 應用程式 → 已安裝的應用程式」解除安裝，
也可以從開始功能表選擇「解除安裝」。
安裝版已使用專屬的透明文件圖示。

攜帶版／原始碼包：
將整個 ZIP 解壓縮，雙擊 PDFReader.exe，再選擇 PDF。
也可以把 PDF 拖入程式視窗，或把 PDF 檔案拖到 PDFReader.exe 上。
不需要安裝程式、不需要管理員權限。

閱讀介面
啟動時最大化。每一頁等比例填滿閱讀區寬度，左右沒有額外邊距。
保留 PDF 本身的紙張比例與頁內留白，避免文字被橫向拉扁。
頁面由上到下連續排列。沒有工具列、功能選單或閱讀區右鍵選單。
視窗保留 Windows 標題列與原生捲動條；F11 可切換全螢幕閱讀。

操作
觸控螢幕：雙指捏合／張開縮放；手指拖曳捲動。
觸控板：雙指捏合／張開縮放；雙指滑動捲動。
觸控板需在 Windows／驅動程式設定中啟用縮放手勢。
滑鼠：滾輪捲動；Ctrl＋滾輪縮放；按住左鍵拖動頁面。
Ctrl+O：開啟另一個 PDF。
Ctrl+0：恢復適合視窗寬度。
Ctrl+加號／減號：縮放。
Page Up／Page Down／空白鍵：上下捲動一個閱讀區。
方向鍵：上下／左右移動。
Home／End：到文件開頭／結尾。
F11：進入或退出全螢幕；Esc：退出全螢幕。

縮放時以手勢中心／滑鼠位置為基準，先立即調整畫面，
手勢停止後以較高解析度重新繪製。特別高的縮放比例會限制
單頁圖片尺寸，以控制記憶體用量。

系統
適用 Windows 11 64 位元 Intel／AMD 電腦。
PDF 引擎使用 Windows.Data.Pdf；圖像解碼使用 Windows WIC。
程式只有一個執行檔，讀取本機 PDF，程式碼沒有網路請求。
遇到需要開啟密碼的文件時會顯示密碼輸入視窗。

版本狀態
這是未進行數位簽署的第一版試用程式。
已交叉編譯 Windows GUI 執行檔，檢查系統依賴與內嵌 DPI 資訊。
已通過寬度、混合頁面比例、縮放中心、視窗大小變更、捲動邊界，
以及 10,000 組隨機版面／圖片尺寸測試。
目前的開發環境無法執行 Windows 11，因此 Windows PDF 核心的
實際開檔、畫面與觸控硬體操作尚未在 Windows 實機測試。
安裝／解除安裝流程也尚未在 Windows 實機執行。
tests 資料夾提供 Windows 原生開檔與繪圖診斷腳本。

修改與重建
source 資料夾包含完整 C++ 原始碼與 build.py。
重建需要 Python 3 和官方 Zig 0.14.1 或相容版本：
  python source/build.py --zig <zig 執行檔的完整路徑>
重建結果在 package/PDFReader.exe。
程式本身不需要 Python 或 Zig。
重建安裝版：
  python source/build_installer.py --zig <zig 執行檔的完整路徑>
安裝包輸出在此資料夾的上一層。
